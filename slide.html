PARTE 1 · FUNDAMENTOS

Trade-offs: onde o Cacti é forte?

Vantagens concretas e limitações técnicas que precisam ser consideradas.

✓ VANTAGENS

  • Software livre GPLv2 e amplo ecossistema.
  • Séries históricas e análise de capacidade.
  • Retenção previsível por RRD.
  • SNMP, scripts, templates e automação.

△ LIMITAÇÕES

  • Instalação e manutenção exigem planejamento.
  • Granularidade definida pelo polling.
  • Consolidação pode ocultar detalhes.
  • Alertas e análises avançadas podem exigir componentes adicionais.
O Cacti não substitui sozinho logs, NetFlow/sFlow, tracing ou uma plataforma completa de observabilidade.
Open source não implica custo operacional zeroCacti · Features and architecture ↗

PARTE 2 · SNMP

Operações SNMP: o que cada mensagem faz?

As operações SNMP permitem descobrir, consultar e acompanhar métricas no Cacti.

COLETA UTILIZADA NO MONITORAMENTO

GET · GETNEXT · GETBULK

Consulta um valor, percorre OIDs ou recupera vários valores.

Ex.: ler ifHCInOctets de uma interface.
RETORNO

RESPONSE

Retorna o valor solicitado e o mesmo identificador da consulta (Request-ID).

ESCRITA CONTROLADA

SET

Solicita alteração em uma variável gravável. Não é permitido no acesso RO.

NOTIFICAÇÕES

TRAP · INFORM

Trap avisa eventos; Inform também solicita uma confirmação.

COMO ESSAS OPERAÇÕES ENTRAM NO CACTI
01 · DESCOBERTAGETNEXT / GETBULK

Data Query “SNMP - Interface Statistics” encontra ifIndex e ifDescr.

02 · POLLINGGET / RESPONSE

Cacti consulta ifHCInOctets.<índice> em intervalos configurados (ex.: 300 s).

03 · EVENTOSTRAP / INFORM

Notificações exigem receptor ou integração; não são o polling padrão do Cacti.

No Cacti, a coleta é principalmente pull: a ferramenta consulta periodicamente os agentes.RFC 3416 · Operações SNMP ↗

MIB e OID: como localizar uma métrica?

Uma MIB define os objetos; cada OID aponta para um contador ou outra informação.

HIERARQUIA DE OIDs · IF-MIB
Raiz: iso(1) → org(3) → dod(6) → internet(1) → mgmt(2) → mib-2(1)
32 BITS · ifTable
interfaces(2) → ifTable(2) → ifEntry(1) → ifInOctets(10)
ifInOctets.21.3.6.1.2.1.2.2.1.10.2
64 BITS · ifXTable
ifMIB(31) → ifMIBObjects(1) → ifXTable(1) → ifXEntry(1) → ifHCInOctets(6)
ifHCInOctets.21.3.6.1.2.1.31.1.1.1.6.2

“.2” é um exemplo de índice de interface (ifIndex); o valor real depende do equipamento.

CONTADORES · DOIS RAMOS DA IF-MIB
ObjetoOID base (sem índice)Tipo

PARTE 3 · LABORATÓRIO

Dos octetos aos megabits por segundo

O agente informa contadores cumulativos; a taxa resulta da variação no tempo.

R = (C₂ − C₁) × 8 / Δt
14h001.200.000.000octetos
14h051.500.000.000octetos
300.000.000 × 8 ÷ 300 = 8 Mbps

Exemplo hipotético, sem reinicialização ou volta do contador no intervalo.

ATENÇÃO AOS 32 BITS34,36 sTempo aproximado para um contador Counter32 dar uma volta a 1 Gbps de tráfego contínuo.
2³² × 8 ÷ 10⁹ ≈ 34,36 s
RFC 2863: prefira ifHCInOctets / ifHCOutOctets (64 bits) para interfaces rápidas e verifique descontinuidades.
Diferença entre amostras mede taxa média no intervalo — não captura microburstsRFC 2863 · High Capacity Counters ↗
